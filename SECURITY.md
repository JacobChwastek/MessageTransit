# MessageTransit security policy

Adapted from the MassTransit security policy for MessageTransit.

## Supported versions

MessageTransit has no published, supported release yet. The first intended public packages are prereleases for .NET 10. Each release will identify the packages, transports, persistence providers, and versions that were actually verified. The inherited MassTransit 8.x support table does not apply to this fork.

## Reporting a vulnerability

Please do not publish vulnerability details, exploit steps, or sensitive data in a public issue or discussion.

The chosen reporting route is **GitHub private vulnerability reporting** for [JacobChwastek/MessageTransit](https://github.com/JacobChwastek/MessageTransit). As of 2026-09-27, that GitHub feature is **not enabled yet**. It must be enabled and this section updated before the first public NuGet prerelease. Once active, use the repository's **Security → Advisories → Report a vulnerability** button to submit a private report.

The maintainer will review reports on a best-effort basis, assess affected released versions, and coordinate a fix, mitigation, and disclosure when practical. There is no guaranteed response or fix time and no bug bounty.
