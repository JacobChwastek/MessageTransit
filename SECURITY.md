# MessageTransit security policy

Adapted from the MassTransit security policy for MessageTransit.

## Supported versions

MessageTransit publishes prereleases for .NET 10, and none is designated as a supported release. Each GitHub release identifies the packages, transports, persistence providers, and versions that were verified. The inherited MassTransit 8.x support table does not apply to this fork.

## Reporting a vulnerability

Please do not publish vulnerability details, exploit steps, or sensitive data in a public issue or discussion.

Report a suspected vulnerability privately through GitHub: open the repository's **Security** tab, choose **Advisories**, then **Report a vulnerability**, or use the [reporting form](https://github.com/JacobChwastek/MessageTransit/security/advisories/new) directly.

The maintainer reviews reports on a best-effort basis, assesses affected released versions, and coordinates a fix, mitigation, and disclosure when practical. There is no guaranteed response or fix time and no bug bounty.
