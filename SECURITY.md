# MessageTransit security policy

Adapted from the MassTransit security policy for MessageTransit.

## Supported versions

This repository does not currently advertise a supported MessageTransit release. The first intended public packages are prereleases for .NET 10. Each release will identify the packages, transports, persistence providers, and versions that were actually verified. The inherited MassTransit 8.x support table does not apply to this fork.

## Reporting a vulnerability

Please do not publish vulnerability details, exploit steps, or sensitive data in a public issue or discussion.

The intended reporting route is **GitHub private vulnerability reporting** for [JacobChwastek/MessageTransit](https://github.com/JacobChwastek/MessageTransit). As checked on **2026-10-10**, that feature is **disabled**. No active confidential reporting channel is advertised for this fork. GitHub Issues and Discussions are also disabled. See [SUPPORT.md](SUPPORT.md) for current contact availability.

Private vulnerability reporting must be enabled and this section updated before the first public NuGet prerelease. Once enabled, the repository's **Security → Advisories → Report a vulnerability** button will provide the private reporting route.

When a reporting route is available, the maintainer intends to review reports on a best-effort basis, assess affected released versions, and coordinate a fix, mitigation, and disclosure when practical. There is no guaranteed response or fix time and no bug bounty.
